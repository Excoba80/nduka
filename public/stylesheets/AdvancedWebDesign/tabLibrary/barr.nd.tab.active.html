Active Tabs

To highlight the current tab/page the user is on, add a color class, and use JavaScript to update the active link.In the example below, we have added a "tablink" class to each link. That way, it is easy to get all links that is associated with tabs, and give the current tab link a "w3-red" class, to highlight it:
