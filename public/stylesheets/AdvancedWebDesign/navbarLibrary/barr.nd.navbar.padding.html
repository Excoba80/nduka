Navigation Bar Sizes

Add the w3-padding-classes to change the padding of each element inside the navigation bar.

w3-padding-small:

Home Link 1 Link 2

Default:

Home Link 1 Link 2

w3-padding-large:

Home Link 1 Link 2

w3-padding-16:

Home Link 1 Link 2

w3-padding-24:

Home Link 1 Link 2

w3-padding-32:

Home Link 1 Link 2

Note: You can also add padding to the navigation bar, instead of each link. However, if you do this, note that the links do not get full padding on hover:

w3-padding-small:

Home Link 1 Link 2

w3-padding:

Home Link 1 Link 2

w3-padding-large:

Home Link 1 Link 2
